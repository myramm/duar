Kebijakan Privasi (Privacy Policy)

Terakhir Diperbarui: 18 September 2026

1. Pendahuluan

Selamat datang di DUAR ("kami", "aplikasi"). Kami sangat menghargai dan berkomitmen untuk melindungi privasi serta keamanan data pribadi pengguna kami. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda saat menggunakan web app DUAR, termasuk integrasi dengan layanan Google OAuth dan Google Drive AppData Cloud Storage.

2. Informasi yang Kami Kumpulkan

Kami hanya mengumpulkan data yang benar-benar dibutuhkan untuk menyediakan dan mempersonalisasi fungsi aplikasi:

  • Informasi Akun Google: Ketika Anda memilih untuk masuk menggunakan Google (Google Sign-In), kami menerima informasi profil publik dasar yang mencakup Nama Lengkap, Alamat Email, dan Foto Profil (Google ID token). Informasi ini digunakan semata-mata untuk mengidentifikasi akun Anda dan menampilkan profil pada UI Account Selector.
  • Data Konfigurasi & Preferensi Aplikasi: Data seperti daftar paket favorit/bookmark, riwayat transaksi, dan preferensi antarmuka pengguna.
3. Penggunaan Izin Google OAuth & Google Drive (AppData)

Aplikasi kami menggunakan cakupan izin (scopes) Google OAuth resmi berikut:

openid email profile

Digunakan untuk memverifikasi identitas pengguna secara aman, menampilkan akun aktif, dan mendukung fitur Multi-Account Picker tanpa menyimpan kata sandi Anda.

https://www.googleapis.com/auth/drive.appdata

Digunakan khusus untuk membaca dan menulis file konfigurasi terenkripsi (duar-user-data.json) pada folder khusus aplikasi (Application Data Folder) di Google Drive pribadi milik Anda sendiri.

Penting mengenai Akses Google Drive: DUAR TIDAK memiliki akses ke dokumen, foto, file pribadi, atau folder umum di Google Drive Anda. Izin drive.appdata hanya mengizinkan aplikasi mengakses folder data tersembunyi milik DUAR itu sendiri sehingga file Anda lainnya 100% aman dan tidak tersentuh.
4. Kepatuhan Kebijakan Pengguna Layanan Google API

Penggunaan dan transfer informasi yang diterima DUAR dari Google API ke aplikasi lain akan selalu mematuhi Google API Services User Data Policy, termasuk persyaratan Penggunaan Terbatas (Limited Use requirements):

  • Kami tidak menjual data pribadi atau data Google Anda kepada pihak ketiga mana pun.
  • Kami tidak menggunakan data Google Anda untuk tujuan periklanan atau penargetan iklan.
  • Kami tidak mentransfer atau menggunakan data Google pengguna untuk melatih model kecerdasan buatan (Artificial Intelligence / Machine Learning) umum.
  • Akses data dibatasi hanya untuk fungsi aplikasi yang diminta secara langsung oleh pengguna.
5. Penyimpanan dan Keamanan Data

Keamanan informasi Anda adalah prioritas utama kami:

  • Penyimpanan Sisi Pengguna (Client-Side Storage): Data sesi dan token disimpan di penyimpanan aman lokal peramban (localStorage / sessionStorage) dan disinkronkan ke Google Drive pribadi Anda.
  • Enkripsi Transport (HTTPS): Seluruh pertukaran data antara peramban Anda, server DUAR, dan Google API dilindungi menggunakan enkripsi standar industri Transport Layer Security (TLS/HTTPS).
6. Hak dan Pengendalian Data Pengguna

Anda memiliki kendali penuh atas data dan akun Anda:

  • Keluar & Hapus Akun Lokal: Anda dapat keluar kapan saja atau menghapus akun dari daftar pemilih akun DUAR melalui tombol profil akun di aplikasi.
  • Mencabut Akses Google OAuth: Anda dapat mencabut izin aplikasi DUAR kapan saja langsung dari pengaturan keamanan Google Anda melalui Google Account Third-party apps with account access.
7. Perubahan pada Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu untuk menyesuaikan dengan pembaruan fitur atau ketentuan hukum yang berlaku. Setiap pembaruan akan dipublikasikan pada halaman ini dengan tanggal pembaruan terbaru.
